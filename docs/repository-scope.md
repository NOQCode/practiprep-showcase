# Public Repository Scope

This repository is a public showcase for PractiPrep. It is designed to show the product clearly while protecting proprietary work.

## What This Repository Shows

- Product positioning
- Public screenshots
- Feature overview
- High-level technology stack
- High-level architecture notes
- Website and App Store links

## What This Repository Does Not Show

- Production source code
- Real exam question database
- Answer explanations and solution logic
- AI system prompts or model-routing logic
- Supabase Edge Functions
- RevenueCat or StoreKit implementation
- Environment variables or API keys
- Internal planning notes or development history

## Why This Boundary Exists

The value of PractiPrep is not only the visual interface. It also includes the learning content, data structure, subscription implementation, backend workflows, AI integration, and product-specific UX decisions.

Publishing those parts would make the app unnecessarily easy to copy. This repository therefore acts as a professional public product case study rather than an open-source release.
