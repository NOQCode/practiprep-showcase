# Privacy Overview

PractiPrep is built as an account-based learning app with premium and AI-supported features. This overview is public-facing and intentionally high level.

## Data Categories

Depending on how the app is used, the production app may process:

- Account information required for login
- Subscription entitlement status
- Learning progress and app preferences
- AI chat input and task context when the AI assistant is used
- Technical request data needed to keep paid features stable and secure

## Third-Party Services

The production app may integrate with:

- Supabase for authentication and backend-backed app features
- RevenueCat for subscription entitlement management
- Apple App Store for iOS subscriptions and purchases
- Anthropic Claude API for AI-supported explanations and learning assistance

## User Control

PractiPrep is designed to provide user-facing controls for account management, subscription management, privacy information, and account deletion.

## Repository Boundary

This showcase repository contains no user data, no production database, no analytics data, no AI chat history, and no backend credentials.
